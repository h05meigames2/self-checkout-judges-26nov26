## What it does

`main.py` writes one original funny remark in the voice of a smug,
judgmental self-checkout machine to `/output/entry.txt`. The program is
deterministic — every run writes the same line — uses only the standard
library, and needs no network access.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

## The line

> Twelve yoghurts and nothing else. I've scanned your whole personality. It expires before the yoghurts do.

(105 characters — inside the 1–200 character gate.)
